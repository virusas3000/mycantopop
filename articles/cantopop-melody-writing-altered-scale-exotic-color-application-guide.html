廣東歌旋律創作變音階異國色彩應用指南：點樣用 altered scale 令旋律更有張力

2026年09月11日 · 廣東歌·為你

變音階異國色彩旋律創作指南。教你用 altered scale 喺廣東歌旋律中加入變化音，制造出獨特嘅異國色彩同和聲張力。

變音階嘅基本結構

變音階（Altered Scale）係一種七音階，屬於旋律小調嘅第七模式。佢嘅音階結構係：根音、降二音、降三音、自然三音、降五音、升五音、降七音。用C做例子就係：C、Db、Eb、E、Gb、Ab、Bb。呢個音階最特別嘅地方係佢包含咗所有可能嘅變化音——降二、升九、升十一、降十三——全部都係屬七和弦嘅變化延伸音。

呢個音階喺爵士音樂入面非常常見，通常用喺 ii-V-I 進行嘅 V 和弦上面。但喺廣東歌入面，我哋可以借用呢個音階嘅部分元素，為旋律注入一種獨特嘅異國色彩同和聲張力。唔需要成個音階用晒，即使只用其中幾個變化音，都已經可以產生明顯嘅效果。

要理解變音階嘅效果，可以用一個簡單嘅比喻：如果自然大調係白光，變音階就好似三棱鏡折射出嚟嘅彩色光譜——佢包含咗所有可能嘅色彩選項，你只需要揀選其中一兩種嚟點綴旋律。

喺廣東歌旋律中應用變化音

直接用成個變音階嚟寫廣東歌旋律可能會太過爵士味，但選擇性地使用其中嘅變化音就可以達到好嘅效果。最常見嘅用法係喺副歌嘅結尾或者過渡段落入面，用一個降二音或者升十一音去制造一種「懸而未決」嘅感覺。

例如，喺C大調嘅歌曲入面，副歌最後一句可以嘗試用Db（降二音）取代C或者D，做一個半音嘅下滑或者上行。呢個音會令聽眾感到一絲意外，但唔會太過突兀。然後再解決到C或者去到下一個和弦嘅根音，就完成咗一個微妙嘅異國色彩點綴。

另一個用法係喺Bridge段落入面用更密集嘅變化音。Bridge本身就有轉換情緒嘅功能，加入變音階嘅元素可以加強呢種轉換嘅效果。例如可以嘗試用降五音同升五音交替出現，制造一種不穩定嘅感覺，然後喺進入最後一次副歌之前解決到主調。

同和弦配合嘅技巧

用變化音嘅時候，要考慮背後嘅和弦支援。變音階最自然嘅和弦環境係屬七變化和弦，例如 C7#9、C7b13、C7#5b9 等等。當旋律用緊變化音嗰陣，和弦最好都有對應嘅變化延伸音，咁樣旋律同和弦先至會和諧一致。

如果唔想用太複雜嘅和弦，可以用一個簡單嘅屬七和弦（例如 G7），然後喺旋律入面用變音階嘅音。G7本身已經包含咗G、B、D、F，而變音階嘅音（Ab、Bb、C、Db、Eb）就會好似「浮喺上面」嘅色彩音，令簡單嘅和弦聽起嚟更豐富。

對於廣東歌常見嘅流行和弦進行，例如 I-V-vi-IV（C-G-Am-F），可以喺V和弦嗰段加入變化音。例如喺G和弦嘅小節入面，旋律用Ab（降九音）或者Eb（降十三音），就會令呢個G和弦聽起嚺更有色彩。但要留意唔好喺每個V和弦都用，否則會失去新鮮感。

變音階同粵語聲調嘅關係

粵語有九聲六調，每個字嘅音高相對固定。用變化音嗰陣要特別注意聲調同音高嘅配合。變化音通常係半音嘅偏移，呢種偏移可能會令某啲字嘅聲調聽起嚟唔太自然。

解決方法之一係選擇聲調比較中性嘅字去配合變化音。例如粵語嘅陰平同陽平聲調比較容易配合半音嘅偏移，因為佢哋嘅音高範圍較闊。而入聲字（例如以 -p, -t, -k 結尾嘅字）就比較難配合，因為入聲字嘅時值通常好短，冇足夠嘅時間去展現變化音嘅色彩。

另一個技巧係將變化音放喺無字嘅位置——即係旋律嘅過渡音或者裝飾音。呢樣就可以享受變音階嘅色彩，同時唔使擔心聲調匹配嘅問題。例如喺兩個字之間嘅旋律過渡加入一個經過音，用變音階嘅音去做半音階滑行。

實際案例示範

假設我哋寫一首C大調嘅廣東歌，副歌和弦進行係 C - G7 - Am - F。喺G7嗰個小節，旋律原本可能係 B - C - D - C，我哋可以嘗試改成 B - Bb - C - Db - C。呢度用咗Bb（升九音）同Db（降九音），兩個都係G7嘅變化延伸音，會令G7和弦聽起嚟更有色彩。

再進一步，可以喺Bridge段落將和弦改為 C - C7#9 - Fm7 - C7#9 - G7。C7#9 係一個典型嘅藍調爵士和弦，喺呢度用作通往Fm7嘅橋樑。旋律可以用C變音階嘅音：C、Db、Eb、E、Gb、Ab、Bb，制造一段充滿異國色彩嘅Bridge，然後解決到最後一次副歌嘅C大調。

呢種做法喺陳奕迅、林家謙等歌手嘅作品中都可以搵到類似嘅手法。佢哋唔會成首歌都用變音階，而係喺關鍵嘅位置用一兩個變化音去做點綴，令旋律喺流行嘅基礎上有一絲與眾不同嘅味道。

總結

變音階係一個強大嘅旋律創作工具，可以為廣東歌注入獨特嘅異國色彩同和聲張力。關鍵係選擇性地使用，而唔係成首歌都用晒。透過喺副歌結尾、Bridge段落或者和弦過渡入面加入一兩個變化音，你就可以令旋律喺保持流行感嘅同時，有一種令人耳目一新嘅色彩。記住要留意粵語聲調嘅配合，確保變化音唔會影響歌詞嘅自然語感。
