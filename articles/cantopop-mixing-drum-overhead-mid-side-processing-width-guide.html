鼓組overhead中側處理立體聲宽度混音指南。教你用M/S處理技術令廣東歌鼓組overhead更寬闊更有空間感。

Overhead同M/S處理嘅基礎

Overhead麥克風係鼓組錄音入面負責捕捉整體鼓組聲音同空間感嘅一對麥克風。佢哋通常以一對立體聲方式放置喺鼓組上方，記錄住所有鼓同鈸嘅聲音，以及房間嘅自然殘響。Overhead嘅質素很大程度上決定咗鼓組喺混音入面嘅整體感覺。

M/S（Mid-Side）處理係一種立體聲處理技術，將立體聲信號分解為中間信號（Mid，即左右通道相同嘅部分）同側邊信號（Side，即左右通道唔同嘅部分）。Mid包含咗主要嘅聲音內容——通常係鼓組嘅中心元素如踢鼓同軍鼓——而Side就包含咗空間信息同立體聲宽度——通常係鈸聲同房間反射。

透過分別處理Mid同Side信號，你可以獨立控制鼓組嘅中心定位同空間宽度。例如你可以增強Side信號令鈸聲更寬闊，同時保持Mid信號嘅踢鼓同軍鼓喺正中心唔受影響。呢種精度係普通左右立體聲處理做不到嘅。

M/S編碼同解碼

要進行M/S處理，首先需要將左右立體聲信號編碼為M/S信號。Mid信號 = （Left + Right）/ 2，Side信號 = （Left - Right）/ 2。呢個過程可以由M/S插件自動完成，例如 Brainworx bx_digital、FabFilter Pro-Q 3 嘅 M/S 模式、或者 Waves S1 IMS Processor。

處理完之後，需要將M/S信號解碼返做左右立體聲：Left = Mid + Side，Right = Mid - Side。同樣呢個步驟通常由插件自動完成。你要做嘅就係喺M/S模式入面分別對Mid同Side通道進行處理。

對於overhead嚟講，M/S處理嘅一個重要應用係喺Mid通道做EQ調整。因為Mid通道主要包含踢鼓同軍鼓嘅聲音，你可以喺Mid通道用EQ增強踢鼓嘅攻擊力（例如喺3kHz到5kHz提升2到3dB）或者軍鼓嘅厚度（例如喺200Hz到250Hz提升1到2dB），而呢啲調整唔會影響Side通道入面嘅鈸聲同空間感。

用M/S EQ擴展立體聲宽度

擴展overhead嘅立體聲宽度係M/S處理最常見嘅應用之一。方法好簡單：將Side通道嘅音量提高2到4dB。因為Side信號代表嘅係立體聲差異，提高佢嘅音量會令聽眾感覺到聲音由兩邊喇叭向外擴展。

更精細嘅做法係用M/S EQ選擇性咁擴展特定頻率嘅宽度。例如喺8kHz到12kHz嘅範圍（鈸聲嘅主要頻率）提升Side通道3到5dB，可以令鈸聲聽起嚟更寬闊更有空氣感。同時喺100Hz以下嘅範圍衰減Side通道3到6dB，確保低頻保持喺中心位置唔會四散。

要注意唔好過度擴展。如果Side通道嘅音量太高，會令聲音聽起嚟「空洞」或者「散」，失去中心嘅焦點。一個好嘅檢查方法係喺mono播放嗰陣聽——如果mono版本嘅聲音明顯比立體聲版本弱好多，表示Side通道嘅比例可能太高。理想嘅狀態係立體聲版本寬闊而mono版本依然清晰有力。

用M/S壓縮控制動態

除咗EQ，M/S壓縮亦係overhead處理嘅有力工具。喺Mid通道做壓縮可以控制踢鼓同軍鼓嘅動態，令佢哋更穩定。例如用一個壓縮器，比例3:1，閾值設喺-15dB，攻擊時間10ms，釋放時間100ms，可以令Mid通道嘅動態更一致，而唔影響Side通道嘅自然空間感。

另一個有趣嘅用法係喺Side通道做向上壓縮（Upward Compression）或者擴展（Expansion）。向上壓縮可以增強微弱嘅Side信息——例如遠處嘅鈸聲同房間反射——令overhead嘅空間感更豐富。設置方法係用一個低比例（1.5:1到2:1）嘅壓縮器，閾值設喺-40dB左右，攻擊同釋放都設慢啲（50到200ms），令處理更自然。

如果overhead嘅房間反射太多，想令鼓組聽起嚟更乾，可以喺Side通道做擴展（Expansion）。擴展器會將低於閾值嘅信號再降低， effectively 減弱微弱嘅Side信息。設置方法係用一個向下擴展器，閾值設喺-35dB左右，比例2:1，可以減弱房間反射同時保留主要嘅鈸聲。

同近場麥克風嘅融合

Overhead通常同近場麥克風（close mic，例如每個鼓同鈸都有自己嘅麥克風）一齊使用。M/S處理overhead嗰陣要考慮同近場麥克風嘅融合。一個常見問題係overhead嘅鈸聲同近場麥克風嘅鈸聲喺立體聲宽度上唔一致——近場麥克風通常係mono（定位喺某個點），而overhead係stereo（有宽度）。

解決方法之一係用M/S處理將overhead嘅鈸聲宽度調整到同近場麥克風嘅定位配合。例如如果hi-hat嘅近場麥克風pan到左邊45度位置，overhead嘅Mid通道可以用EQ喺hi-hat嘅頻率範圍做少少衰減，令hi-hat喺overhead入面嘅定位更偏向Side通道，配合近場麥克風嘅panning。

另一個做法係將overhead嘅Mid通道同近場麥克風嘅bus做平行壓縮。將overhead嘅Mid通道send到一個平行壓縮bus，同近場麥克風嘅平行壓縮bus混合，可以令鼓組嘅中心元素（踢鼓同軍鼓）更厚實有力，同時Side通道嘅自然空間感保持唔變。

常見問題同注意事項

一個常見問題係M/S處理後overhead嘅相位出現問題。因為M/S編碼同解碼涉及信號嘅加減運算，如果原本嘅左右信號有相位差異，M/S處理可能會放大呢個差異，導致mono相容性下降。解決方法係喺M/S處理之前先檢查overhead嘅相位，確保左右麥克風嘅時間差喺合理範圍內。

另一個問題係過度嘅宽度擴展令overhead喺耳機上聽起嚟唔自然。耳機將左右聲道直接送入左右耳，冇交叉饋送（crosstalk），所以過寬嘅聲音喺耳機上會聽起嚟「分離」而唔係「寬闊」。建議喺唔同播放系統（喇叭、耳機、手機喇叭）上都測試overhead嘅宽度效果，確保喺所有系統上都聽起嚟自然。

最後要注意嘅係，M/S處理雖然強大，但唔係唯一嘅工具。有時簡單嘅立體聲EQ或者寬度控制插件已經足夠。M/S處理最適合需要精確控制中間同側邊信號嘅情況，例如當你想增強鈸聲嘅宽度但唔影響踢鼓嘅中心定位嗰陣。唔好為咗用而用，要根據實際需要去選擇。

總結

M/S處理係廣東歌混音入面處理鼓組overhead嘅一個強大工具。透過將立體聲信號分解為Mid同Side通道，你可以獨立控制鼓組嘅中心定位同空間宽度，達到普通立體聲處理做不到嘅精度。關鍵在於理解Mid同Side各自代表嘅內容，以及用EQ、壓縮等工具分別處理佢哋。記住要適度使用，過度嘅宽度擴展或者動態處理都會令聲音不自然。喺唔同播放系統上測試，確保你嘅M/S處理喺所有環境下都聽起嚟自然有力。
