旺角busking新手入門指南：第一次廣東歌街頭表演要做啲咩

旺角busking新手入門：由零開始嘅第一步

你想喺旺角唱廣東歌做busking，但唔知由邊度開始？呢篇旺角busking新手入門指南就係為你而寫嘅。我哋會由最基本嘅問題講起——第一次去旺角busking要做啲咩準備？要買咩設備？要唱咩歌？點樣克服緊張？第一次表演嘅目標係咩？——一步一步帶你由零開始，完成你嘅第一次街頭表演。

廣東歌·為你團隊每一位成員都經歷過「第一次busking」嘅恐懼同興奮。我哋記得第一次企喺旺角行人專用區、對住一個音箱、手拎住麥克風、望住路人行過嘅嗰種忐忑——心跳加速、手心出汗、聲音發抖。但係我哋亦記得第一次有人停低聽完一首歌、第一次有人放HK$20入打賞箱、第一次有路人話「唱得好好聽」嘅嗰種感動。呢種感動令我哋一直做到而家。如果你都想體驗呢種感動，呢篇指南會幫你跨過第一個門檻。

好多新手對busking有好多恐懼：「我唱得唔夠好」、「冇人會停低聽」、「我會唔會俾人驅趕」、「我會唔會好樣衰」。呢啲恐懼全部係正常嘅——每個busker第一次都會有。但係呢啲恐懼全部可以透過準備同行動去克服。記住一個事實：旺角每個夜晚有20–30個busker表演，佢哋全部都經歷過第一次。如果佢哋做到，你都做到。以下我哋會用最詳細、最實用嘅方式，教你完成第一次旺角busking。

新手入門嘅三大心理準備

喺講實際操作之前，先做好心理準備。第一，接受唔完美——你嘅第一次busking一定唔會完美，可能會走音、會忘詞、會緊張到聲音發抖。呢啲全部係正常嘅。第一次嘅目標唔係「完美表演」，而係「完成表演」——你企出嚟、唱完一個Set、收工走人，就已經係成功。第二，唔好在意Tips——第一次可能只係HK$50–100，甚至更少。Tips唔係衡量你表演好唔好嘅標準——第一次嘅重點係經驗累積。第三，路人唔會記住你——你好驚嘅「好樣衰」其實唔會發生，因為路人行過就行咗，佢哋唔會記住你嘅表現。呢個事實反而令人安心——你嘅「失敗」根本冇人會記得。

第一步：實地考察——了解旺角busking現場

喺你做任何準備之前，第一件事係去旺角行人專用區實地考察。呢一步好多新手跳過，直接買設備就開始表演——結果往往因為唔了解現場情況而手忙腳亂。實地考察係你嘅「免費學費」。

考察嘅具體做法

建議你去旺角行人專用區考察3–4次，每次至少逗留1–2個鐘。最好嘅考察時間係平日嘅晚上7–9點同週末嘅晚上8–10點——呢兩個時段係busking嘅黃金時段，你可以見到最多busker表演。考察時需要留意以下幾點：

  • 人流模式：人流高峰係幾時？路人行得快定慢？邊類人最多（上班族、年輕人、遊客）？邊類人會停低聽歌？
  • busker嘅表現：有幾多個busker？佢哋企喺邊個位置？唱咩類型嘅歌？用咩設備？音量去到幾大？
  • 觀眾反應：邊個busker最多人圍觀？佢哋唱邊首歌最多人停低？觀眾停留幾耐？有冇人打賞？打賞幾多？
  • 環境因素：附近有冇商舖投訴噪音？有冇食環署巡邏？路邊有冇遮擋落雨嘅地方？
  • 位置選擇：邊個位置最適合你？考慮人流、空間、同其他busker嘅距離、以及附近有冇住宅（噪音問題）

考察記錄方法

帶一個記事簿或者用手機備忘錄記錄你嘅觀察。每個位置記錄：時間、人流估計、主要人群類型、已經有幾多個busker、呢個位置嘅優點同缺點。考察3–4次之後，你就會對旺角busking嘅現場有一個清晰嘅畫面，知道邊個位置適合你、邊個時段最好、同埋你需要點樣準備。呢個考察過程亦會令你對旺角嘅環境更加熟悉——到你第一次正式表演嘅時候，你已經唔係「第一次去旺角busking」，而係「去一個你已經熟悉嘅地方表演」。

「考察係你嘅免費學費。用三個禮拜嘅觀察，換嚟三個月嘅少走冤枉路。冇考察就開始表演嘅人，通常頭三個月都喺犯考察就能避免嘅錯誤。」— 廣東歌·為你街頭表演團隊

第二步：設備採購——新手嘅第一套裝備

考察完成之後，就係時候買設備。新手嘅設備採購有一個原則：最基本嘅配置，最有效率嘅投資。唔好一開始就買最貴嘅設備——你未知道自己會唔會持續做busking，過度投資係浪費。以下係新手嘅第一套裝備建議。

慳錢方案：借用同二手

如果HK$6,000–7,000嘅預算對你嚟講都係有壓力，有幾個慳錢方法。第一，借用朋友嘅設備——如果你有玩音樂嘅朋友，問吓佢哋可唔可以借音箱或者麥克風畀你試吓。第二，買二手設備——喺Carousl或者Facebook Marketplace上面，經常有人平價出售用過幾次嘅音箱同麥克風，二手價通常係新價嘅50–70%。第三，先買最基本嘅——如果真係預算有限，可以先買一個藍牙喇叭（HK$500–800）加一個動圈麥克風（HK$200），雖然效果冇專業設備咁好，但足以令你完成第一次表演。等你確認自己會持續busking之後，再逐步升級設備。

設備測試同熟悉

買完設備之後，唔好即刻帶去旺角。先喺屋企做充分嘅測試同熟悉。具體步驟：第一，將所有設備連接好，測試每個連接是否正常。第二，試唱幾首歌，調整音箱音量同EQ至你滿意嘅聲音。第三，模擬戶外環境——打開窗、開風扇製造噪音，測試喺有背景噪音嘅情況下你嘅歌聲能否清晰傳達。第四，練習拆裝設備——你需要喺5–10分鐘內完成所有設備嘅 setup同 pack up，因為現場你可能需要快速搬位。

第三步：歌單準備——你嘅第一個Set

歌單準備係新手最容易忽略但又最影響表演效果嘅環節。以下係你嘅第一個歌單應該點樣準備。

第一次歌單嘅選擇原則

第一次busking嘅歌單應該遵循以下原則：第一，全部唱你最有信心嘅歌——第一次表演已經夠緊張，唔好挑戰你唱得唔熟嘅歌。揀你最熟悉、最有信心唱得好嘅10–15首歌。第二，以高認知度金曲為主——Beyond、張學友、陳奕迅嘅歌路人一聽就識，最容易吸引人停低。第三，避免太難嘅歌——第一次表演唔好挑戰《李香蘭》呢啲高難度嘅歌。揀難度適中、你能夠穩定唱完嘅歌。第四，準備一首原創歌（如有）——如果你有自己寫嘅廣東歌，第一次就可以唱出嚟試水溫。

推薦嘅新手第一個Set歌單

以下係廣東歌·為你團隊推薦嘅新手第一個Set歌單（8首歌，約30分鐘）：

  2. 陳奕迅《富士山下》——保持認知度，展現唱功
  3. 張學友《每天愛你多一些》——經典情歌，吸引中年觀眾
  4. MIRROR《BOSS》或者YAH《世界唔會停》——近年流行，留住年輕人
  5. Beyond《喜歡你》——深情ballad，降溫
  6. 原創廣東歌一首（如有）——展現你嘅個人風格
  7. 林憶蓮《至少還有你》或者王菲《約定》——深情收尾
  8. Beyond《光輝歲月》——壓軸大合唱，製造高潮

練習到唔使睇歌詞

歌單揀好之後，每首歌都要練到「唔使睇歌詞都可以完整唱完」。呢個標準聽落好高，但係其實只要你嘅歌單只有10–15首，每首都係你熟悉嘅歌，練一兩個禮拜就做到。練習方法：喺屋企對住鏡唱、搭巴士嗰陣喺心入面默唱、沖涼嗰陣大聲唱——總之將每首歌重複唱20次以上。現場表演嘅時候，你嘅注意力要放喺觀眾互動同感情表達上面，而唔係放喺「記歌詞」上面。如果你仲要睇歌詞簿，你就冇辦法同觀眾有眼神交流。

第四步：心理建設——克服第一次嘅恐懼

第一次busking最大嘅障礙唔係技術，而係心理。以下係克服恐懼嘅具體方法。

恐懼一：「冇人會停低聽」

呢個恐懼係最常見但亦最容易化解嘅。事實係：如果你唱嘅係高認知度嘅廣東歌（如Beyond《海闊天空》），一定會有人停低——因為呢啲歌嘅認知度超過90%，總會有人因為熟悉嘅旋律而減速。我哋嘅數據顯示，即使係新手，只要唱對歌，第一次表演都會有5–10個人停低聽。你可能覺得5–10個人好少，但係對一個新手嚟講，有5個人停低聽你唱歌已經係一種鼓勵。

恐懼二：「我會走音/忘詞/出醜」

呢個恐懼嘅化解方法就係「練習到熟」。如果你每首歌都練咗20次以上，走音同忘詞嘅概率會大幅降低。即使真係走咗音或者忘咗一兩句詞，都唔好停——繼續唱落去，大部分人根本唔會注意到。記住，路人唔係評判——佢哋唔會逐個音去聽你唱得啱唔啱，佢哋只係享受一首熟悉嘅歌嘅現場演繹。

恐懼三：「我會俾人驅趕/笑」

旺角行人專用區係合法嘅busking場所，只要你唔阻街、唔嘈到人，食環署一般唔會干預。即使被要求停止，通常只係口頭警告，唔會罰款。至於「俾人笑」——事實係旺角嘅人見慣busker，佢哋唔會笑你。即使有人行過嗰陣露出奇怪嘅表情，都唔係笑你——可能只係佢今日心情唔好。記住，路人行過就行咗，佢哋唔會記住你。

帶一個朋友一齊去

非常推薦新手第一次busking帶一個朋友一齊去。朋友嘅作用唔係幫你做嘢，而係提供心理支持——知道現場有一個支持你嘅人，會令你嘅緊張感大幅降低。朋友仲可以幫你：拍照/錄影留念、喺你表演嗰陣幫你睇住設備、喺你休息嗰陣幫你買水、以及喺你表演完之後畀你真實嘅反饋。等你做咗3–4次之後，就可以自己一個去。

「每個busker都記得自己嘅第一次。嗰種心跳加速、手心出汗、唱完之後嘅如釋重負——呢個經歷本身已經值得你企出去。完美唔係目標，勇氣先係。」— 廣東歌·為你創作團隊

第五步：第一次表演實戰——由到場到收工

以下係你第一次旺角busking嘅完整實戰流程，由出門到收工嘅每一步。

出門前嘅準備清單

出門前兩個鐘做最後檢查。用以下清單逐項確認：

  • 所有設備已經 pack 好入袋（音箱、麥克風、麥克風架、流動電源、音樂線）
  • 所有設備電池已經充滿（音箱電池、充電寶、手機）
  • 後備電池帶齊（AA電池8節，如有需要）
  • 歌單已經印好或者存喺手機（雖然你應該唔使睇，但後備無妨）
  • 打賞箱準備好，入面放幾張HK$20「種子錢」
  • 水樽裝滿水、潤喉糖帶咗
  • QR Code牌（PayMe/AlipayHK）已經印好
  • 身分證帶咗（以備查閱）
  • 天氣預測已經 check（冇大雨警告）
  • 如果有朋友一齊去，確認咗集合時間地點

到場同 setup

建議你喺表演前45–60分鐘到達旺角行人專用區。呢個時間用嚟：搵一個啱嘅位置、 setup 設備、調試音量同收音、熱身開聲。第一次建議揀一個唔係最熱門嘅位置——例如山東街交界或者奶路臣街附近——避免直接同資深busker「對撞」。 setup 嘅時候，先擺放音箱喺你前方左側約1.5米處，然後 setup 麥克風架同麥克風，連接好所有線材，最後開機調試。調試時唱一段你嘅開場歌副歌，聽吓收音同音量係咪啱。

開始表演嘅那一刻

當你 setup 完、熱完身、一切準備就緒，就係時候開始。呢一刻係最緊張嘅——深呼吸三次，對自己講「冇嘢好驚，唱就係咁唱」，然後撳播音箱嘅伴奏（如果有），或者撥響結他嘅第一個和弦，開始唱你嘅開場歌。頭30秒係最難嘅——你會覺得自己嘅聲音好細、心跳好快、手好震。但係當你唱完第一首歌嘅副歌，你會發現緊張感開始消退——因為你嘅身體已經適應咗「喺街度唱歌」呢個狀態。到第二首歌嘅時候，你會開始享受；到第三首歌嘅時候，你會開始留意觀眾嘅反應；到第四首歌嘅時候，你會發現原來自己做得到。

表演中嘅注意事項

  1. 音量控制：定期留意你嘅音量係咪適中——如果商舖投訴就即刻調低
  2. 每首歌之後講一句嘢：「多謝大家，下一首係Beyond《喜歡你》」——呢個令你同觀眾有互動
  3. 唔好介意打賞箱空咗：第一次可能好少人打賞，呢個正常
  4. 留意時間：11點半前結束表演，避免噪音管制問題
  5. 遇到執法人員：保持禮貌配合，如果被要求停止就收拾離開
  6. 享受過程：記住你喺度做一件好多人都唔敢做嘅嘢——值得自豪

收工同復盤

表演完之後，花15分鐘做復盤。喺附近嘅茶餐廳坐低，用記事簿記錄以下幾點：邊首歌最多人停低聽？邊首歌你唱得最舒服？邊首歌出咗問題（走音/忘詞）？音量係咪啱啱好？有冇商舖或者食環署嘅干預？第一次嘅Tips總數？呢啲記錄係你下次改進嘅基礎。廣東歌·為你團隊嘅每一位成員都保留住自己嘅busking日誌——呢個習慣令你嘅進步速度比冇做記錄嘅人快好多。

第一次之後：持續成長嘅路線圖

完成第一次busking之後，你已經跨過咗最大嘅門檻。以下係持續成長嘅路線圖。

第二到第四個禮拜：累積經驗

呢個階段每週表演2–3次，每次都做復盤。重點係累積「現場感」——你會發現每次表演都冇上次咁緊張，到第三個禮拜嘅時候，你已經可以自然咁喺街度唱歌。呢個階段嘅Tips每晚約HK$100–200。

第二到第三個月：建立歌單同觀眾群

呢個階段開始擴大歌單到20–25首，加入更多唔同類型嘅歌。你會開始發現有幾個觀眾每次都會嚟聽——記住佢哋嘅面孔同埋同佢哋傾偈。呢個階段可以開始做YouTube直播——雖然初期只有10–20個觀眾，但慢慢會累積。Tips每晚約HK$200–400。

第四到第六個月：線上線下結合

呢個階段你嘅YouTube應該有500–1,000訂閱，開始有線上收入（Super Chat、TikTok打賞）。你嘅旺角街頭表演開始有粉絲專程嚟捧場，Tips穩定喺每晚HK$300–500。月收入可以達到HK$8,000–12,000。呢個時候你已經由「新手」變成「有經驗嘅busker」。

新手最常犯嘅五大錯誤

最後，以下係新手最常犯嘅五大錯誤——提前知道呢啲錯誤可以幫你避免。

錯誤一：音量太大

新手好驚冇人聽到，會將音箱音量調到好大。結果係：商舖投訴、食環署驅趕、隔離busker不滿。正確做法係音量控制喺80–85分貝以內——你可以用分貝計App量度。如果隔離有其他busker，主動行過去同佢協調音量。

錯誤二：阻住商舖出入口

新手好多時唔留意自己嘅設備同觀眾群阻住咗商舖嘅出入口。店舖老闆唔出聲唔代表佢冇意見——佢可能直接打電話投訴。正確做法係 setup 嘅時候留意你同商舖門口嘅距離——至少留1.5米通道。如果你嘅觀眾群開始阻塞通道，主動叫佢哋退後少少。

錯誤三：歌單太冷門

有啲新手想展現自己嘅音樂品味，唱一啲冷門嘅歌。結果係冇人停低——因為路人唔識你唱嘅歌。正確做法係以高認知度金曲為主（佔70%以上），先吸引到觀眾，等佢哋投入之後先唱冷門或者原創歌。

錯誤四：冇帶後備

新手好容易忘記帶後備線、後備電池、後備充電寶。結果係中途斷電或者線壞咗，成個表演要中斷。正確做法係每次出門前用清單檢查，每種線同電池都帶多一份後備。

錯誤五：太在意Tips
